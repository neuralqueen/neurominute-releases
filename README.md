# neurominute — учёт времени (десктоп для Windows)

Приложение для учёта времени и энергии: отмечаешь, чем занят по 15 минут, и день
собирается в наглядную мозаику. Работает **полностью офлайн**, данные хранятся
**только на твоём компьютере** — ни аккаунта, ни сервера, ни слежки.

Этот репозиторий — только для готовых сборок под Windows. Исходный код закрыт.

---

## ⬇️ Скачать и установить

1. Открой раздел **[последний релиз](../../releases/latest)** и скачай установщик
   **`neurominute_…_x64-setup.exe`** (в разделе Assets).
2. Запусти скачанный файл.
3. Windows покажет синее окно **«SmartScreen защитил ваш компьютер»** —
   это нормально для новых программ без платной подписи разработчика.
   Нажми **«Подробнее»**, затем **«Выполнить в любом случае»**.
4. Установщик поставит программу и создаст ярлык. Готово — запускай «neurominute».

**Требования:** Windows 10 или 11, 64-бит.

---

## 🔄 Как обновляться

Когда выйдет новая версия — просто скачай свежий `.exe` из
[Releases](../../releases/latest) и запусти его. Он установится поверх старой
версии. **Твои данные при этом не теряются** — они лежат отдельно от программы.

На всякий случай перед обновлением можно сделать резервную копию:
в приложении открой **⚙️ настройки → раздел «Данные» → «Экспорт»**.

---

## 🔒 Где мои данные

Все записи хранятся в локальной базе на твоём устройстве:

```
%APPDATA%\app.neurominute.desktop\
```

Приложение не выходит в интернет и никуда ничего не отправляет.
Экспорт и удаление данных — в настройках, раздел «Данные».

## 🧪 Что попробовать (для тестировщиков)

- **Таймер «сейчас»** вверху — запусти на текущую активность, потом останови.
- **Сетка дня** — кликни пустую клетку или протяни мышкой интервал, выбери категорию.
- **Хронология дня** — правь описание и уровень энергии прямо в строке.
- **«Моя энергия»** (справа вверху) — отметь состояние сейчас и допиши «что повлияло».
  Отметка появится в хронологии, на графике энергии и в выгрузке для ИИ.
- **Выгрузить для ИИ** (в блоке «Рефлексия дня») — скопируй промпт и вставь в ChatGPT.
- **История** — полистай прошлые дни стрелками.
- **Онбординг** — если хочешь пройти вводный тур заново:
  ⚙️ настройки → **«Показать приветствие снова»** (данные не пострадают).
